Acceso Alpha controlado

El APK se distribuye directamente desde la infraestructura de NEXUS en GitHub Pages. Al pulsar descargar, el navegador recibe el archivo APK sin abrir GitHub Actions ni el repositorio técnico.

02

Verificación de la versión

La página carga automáticamente la versión, el tamaño y el SHA-256 del APK publicado para que puedas verificar exactamente el archivo descargado.

03

Estado de seguridad

La compilación integra identidad criptográfica local, MLS, persistencia cifrada del estado y el núcleo Rust. Sigue siendo una Alpha y no debe considerarse todavía una versión auditada de producción.
