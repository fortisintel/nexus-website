SECURITY

Security should be architecture, not marketing.

NEXUS is being built around verifiable properties: endpoint-owned keys, encrypted content, minimized server knowledge and standards-based cryptography.

End-to-end by designServers transport ciphertext rather than readable message content.
Device-owned identityNo mandatory phone number or email address for core identity.
Standards-based cryptographyNEXUS is validating MLS 1.0 / RFC 9420 through a Rust secure core.
Relay-first callsDesigned so peers do not receive one another's public IP by default.
Minimal metadataLogging and retention are treated as attack-surface decisions.
Independent reviewExternal security review is required before production-grade security claims.
